# YM Live Wallpaper

Живые видео-обои и тонкая настройка интерфейса для десктопного клиента **Яндекс Музыки** на Windows.

Мод встраивает видео за интерфейсом приложения и добавляет панель настроек: шрифты, прозрачность панелей, размытие, компактный сайдбар.

> **Раскладка не меняется** — только оформление. Ничего не удаляется, всё обратимо.

---

## Что умеет

| Раздел | Настройки |
|---|---|
| **Обои** | затемнение, яркость, насыщенность, контраст, виньетка, зерно, выбор видео |
| **Стиль** | масштаб интерфейса, прозрачность и размытие панелей, скругление карточек, компактный сайдбар, скрыть сайдбар, убрать обложки |
| **Шрифт** | 46 гарнитур с живым превью, размер, толщина, межбуквенное, курсив |
| **Плеер** | прозрачность, размытие, скрыть до наведения |
| **Интерфейс** | размер иконок, отступы строк, обесцвечивание/сепия/инверсия обоев, прокрутка |
| **Прочее** | прозрачный сплэш, тень текста |

Панель открывается **шестерёнкой в сайдбаре** или по **Ctrl+Alt+W**.

## Установка

### Вариант 1 — готовый установщик (проще)

1. Скачай **`YM-LiveWallpaper-Setup.zip`** из [Releases](../../releases/latest)
2. Распакуй в любую папку
3. Установи [Яндекс Музыку](https://music.yandex.ru/download/), если ещё нет
4. **Полностью закрой** приложение (включая трей возле часов)
5. Запусти **`УСТАНОВИТЬ.bat`**
6. Запусти Яндекс Музыку

### Вариант 2 — из исходников

```bat
git clone https://github.com/<твой-ник>/ym-live-wallpaper
cd ym-live-wallpaper
npm install
node tools\patch.js
```

Нужен **Node.js 18+**. `node.exe` в установщике поставляется для тех, у кого его нет.

## Как это работает

```
resources\
  app.asar        <- загрузчик мода (заменяет оригинал)
  original.asar   <- оригинальное приложение (бэкап)
Яндекс Музыка.exe <- пропатчен ресурс INTEGRITY/ELECTRONASAR
```

**Загрузчик** (`loader/index.js`):

1. Перехватывает `Module._load`: код приложения получает прокси, где `BrowserWindow` — подкласс мода
2. Подменяет `webPreferences.preload` на свой, путь к оригинальному передаёт через `argv`
3. `app.setAppPath(original.asar)` — чтобы внутренний UI нашёл свои файлы
4. Регистрирует схему `ymwp://` (`stream + bypassCSP`) для загрузки видео в обход CSP
5. Блокирует `electron-updater` — обновление не сломает мод
6. Паузит видео, когда окно невидимо

**Preload** (`loader/preload.js`):

1. Синхронно подгружает оригинальный preload — API приложения не ломается
2. Внедряет `<video>` на `z-index: 0`
3. Снимает чёрные градиенты у корней лейаута, гасит сплэш-скрин
4. Слушает видимость окна и состояние страницы

**Панель** (`loader/settings.js`) — отдельный UI поверх страницы, пишет `settings.json` и применяет изменения сразу.

### Проверка целостности

В exe Яндекс Музыки включён фьюз `EnableEmbeddedAsarIntegrityValidation`: Electron сверяет SHA256 заголовка каждого asar с JSON в PE-ресурсе `INTEGRITY/ELECTRONASAR`. `tools/patch.js` пересчитывает хэши и переписывает ресурс через `resedit`.

> ВАЖНО: мод пишет **две** записи (`app.asar` + `original.asar`). Яндекс читает оба архива, и однократная запись ломает запуск.

## Свои обои

Кладите `.mp4` (H.264, до 1080p) в:

```
%APPDATA%\ym-live-wallpaper\wallpapers\
```

Берётся самый свежий файл. Или через панель: **Обои → Выбрать видео…**

---

## Удаление

Запусти **`УДАЛИТЬ.bat`** из установщика, или:

```bat
node tools\unpatch.js
```

Вернёт `app.asar`, exe и автообновление из бэкапов (`original.asar`, `<exe>.original`, `app-update.yml.bak`).

## Известные ограничения

- **Только Windows** и только десктопный клиент (Electron)
- **Классы Яндекса обфусцированы и меняются между версиями.** После крупного обновления селекторы могут потребовать уточнения — проверяй DevTools (`Ctrl+Shift+I`)
- **Смена цветов интерфейса не поддерживается.** Яндекс задаёт акцент через inline-стили и canvas, CSS их не переписать — попытки через `querySelectorAll` ловили единицы элементов из сотен
- **Автообновление отключено установщиком**, чтобы мод не слетел. Вернуть — `УДАЛИТЬ.bat`
- Сплэш-скрин при запуске убран, окно появляется сразу

## Диагностика

Логи в `%TEMP%`:

| Файл | Что пишет |
|---|---|
| `ymwp-loader.log` | main-процесс: окно, навигация, блокировка updater |
| `ymwp-preload.log` | инъекция видео, ошибки |
| `ymwp-settings.log` | применение настроек |

Сбросить настройки — удалить `%APPDATA%\ym-live-wallpaper\settings.json`.
